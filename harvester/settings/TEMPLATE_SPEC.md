# Settings 中央 JSON 数据底座配置与扩充标准协议

本文件夹（`settings/`）是整个多站自适应外刊智能化收割底座的“数据驱动层”。系统核心逻辑已实现完全解耦，未来不论是修改现有清洗卡尺，还是对接、扩充全新的国际新闻媒体，**均禁止改动任何 Python 核心源码**。


---

## 静态账本分工

```
settings/
├── feeds.json        # 全球外刊实时订阅源集群（网络打卡账本）
└── parsers.json      # 强类型清洗卡尺与多维富媒体硬拦截特征库（规则账本）
```

---

## 账本一：`feeds.json` 语法骨架与规范

负责提供增量与历史同步的 RSS 链接母盘。

### 1. 标准空白填充模版

```json
{
  "媒体代号_版块代号": "对应的官方原生有效的公共标准RSS订阅超链接URL"
}
```

### 2. 字段扩展规约

* **键名（Key）**：必须保持全局唯一，采用纯小写英文字母与下划线拼装（`[site]_[language]_[channel]`）。该键名将直接决定资产在 `articles/` 根目录下的物理文件夹分类命名。
* **键值（Value）**：必须是原厂或可访问的标准 XML / RSS 超链接，严禁携带多余的中文、空格或控制字符。

## 账本二：`parsers.json` 字典底座字段白皮书

负责定义全自动化降维清洗流的所有特征控制阀。

### 1. 标准标准空白配置模版

```json
{
  "site_configs": {
    "目标媒体关键字": {
      "core_selectors": [
        "优先选取的包裹级正文主容器选择器",
        "次级备用包裹标签容器选择器"
      ],
      "paragraph_class_pattern": "正文文本行专属的特征正则字符串",
      "bad_sub_selectors": [
        "需要切除的中插广告样式类名",
        "需要切除的社交分享容器选择器"
      ]
    }
  },
  "hard_meltdown_tags": ["标签名1", "标签名2"],
  "ghost_image_patterns": ["正则指纹1", "正则指纹2"],
  "global_url_block_keywords": ["链接黑名单词1", "链接黑名单词2"]
}
```

### 2. 核心字段定义白皮书

#### A. `site_configs` (多站选择器映射字典)

整个清洗流的“导航仪”。系统在打捞文章时，会自适应嗅探 URL 中的域名关键字，并秒级映射挂载对应的字典配置。

* **`core_selectors`** (数组群)：
* 定义：原刊正文的核心包裹骨架标签容器白名单。
* 语法：支持标准 HTML5 标签名（如 `article`）、CSS 标准类名（如 `.story-body`）或绝对 ID（如 `#main-content`）。
* 扩展逻辑：系统会按照你填写的数组先后顺序进行“瀑布流式”高精卡位，一旦排在前面的选择器命中，后面的备用选择器自动失效。


* **`paragraph_class_pattern`** (正则表达式)：
* 定义：针对部分媒体（如 BBC）由于使用了混淆混淆前端框架、随机生成的动态段落类名空间而设立的特征探针。
* 语法：填入最核心的长常驻字母根（如 `Paragraph`）。系统会利用正则自动做泛泛步匹配。


* **`bad_sub_selectors`** (数组群)：
* 定义：隐藏或穿插在正文主容器内部的无关噪声碎屑。
* 扩展逻辑：系统在落盘前，会对命中该数组中所有类名、ID 的 HTML 组件进行全自动内存级“ Decompose 物理蒸发销毁”，100% 杜绝 Advertisement 广告标语和赞助商引言污染。



#### B. `hard_meltdown_tags` (强类型多媒体实体拦截卡尺)

* 定义：英语精读学术单文件完整性的“把关天网”。
* 语法：直接写入标准的 HTML5 原始标签名。如 `["table", "iframe", "video"]`。
* 运行机制：只要在锁定的正文核心容器内，嗅探到了这些真实的标签对象实体，系统会立刻判定当前页面为“非标富媒体电台/交互页”，自动终止抓取并跳过，确保允许入库落盘的 100% 都是极度适合中国学生打印和阅读的标准图文长文。

#### C. `ghost_image_patterns` (幽灵死图特征指纹库)

* 定义：延迟加载技术产生的空白占位图拦截器。
* 语法：支持标准正则不区分大小写字符串。如 `["/1x1/", "placeholder"]`。
* 运行机制：凡是打捞出来的图片绝对超链接命中了这里的特征，一律在最前端掐断，防止 Markdown 单文件里混入破损的无效裂图。

#### D. `global_url_block_keywords` (上游物理阻断矩阵)

* 定义：对 RSS 增量列表第一时间的“熔断熔断卡尺”。
* 语法：填入 URL 路径中常见的媒体流标志特征段，如 `["/videos/", "/live/"]`。
* 运行机制：只要发现 item 超链接中包含这些词，直接在发起网络请求前将其扼杀，绝不浪费宝贵的公网请求算力与服务器带宽。

## 生产环境宝塔可视化运维规约

1. **JSON 语法死结防御**：
JSON 格式不具备容错性。追加任何配置时，必须确保所有标点、引号、中括号全部为**半角英文状态**。除最后一行外，每个属性块尾部**必须带英文逗号 `,**`。如果不确定格式是否正确，请复制粘贴至 JSON 在线校验器中核对后再保存。
2. **转义斜杠双写铁律**：
在编写 `ghost_image_patterns` 或正则匹配时，如需在 JSON 中使用原生的正则表达式转义字符（如 `\.gif`），**必须强制在 JSON 内部双写斜杠**，写为 `\\.gif`。否则 JSON 解析器在解构时会将其错当成非法转义导致主程序报错。
